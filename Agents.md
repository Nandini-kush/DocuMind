# DocuMind Project Context

DocuMind is an AI-powered document chatbot.

Frontend:
- React.js
- Axios
- Custom CSS

Backend:
- FastAPI
- FAISS
- Sentence Transformers
- FLAN-T5

Features:
- User authentication
- PDF upload
- Semantic search
- RAG-based question answering
- Professional dashboard UI

Goals:
- Modern bright UI with animated backgrounds
- Accurate document-based responses
- Responsive design
- Production-ready code
